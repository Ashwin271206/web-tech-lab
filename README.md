## Experiments

| Lab | Title | Description |
|-----|-------|-------------|
| 1 | [Personal Website](Lab%201%20-%20Personal%20Website/) | A multi-section personal portfolio built with HTML, CSS, and vanilla JavaScript, featuring a glassmorphism UI, tables, and a responsive navbar. |
| 2 | [Job Application Form](Lab%202%20-%20Job%20Application%20Form/) | A two-step registration and job application form with live client-side validation using JavaScript and regular expressions. |
| 3 | [Light & Dark Mode](Lab%203%20-%20Light%20%26%20Dark%20Mode/) | The personal website extended with a light/dark theme toggle using CSS variables, saved in `localStorage`. |
| 4 | [Product Catalog](Lab%204%20-%20Product%20Catalog/) | ShopperzCart, a React product catalog with search, category/price/rating filters, and sorting. |
| 5 | [University Website](Lab%205%20-%20University%20Website/) | A React university website with dropdown menus and multi-page navigation using React Router. |
| 6 | [Counter](Lab%206%20-%20Counter/) | A React counter app demonstrating components, props, state (`useState`), and event handling. |
| 7 | [NodeJS Server](Lab%207%20-%20NodeJS%20Server/) | A Node.js HTTP server built with core modules (`http`, `fs`, `path`) that serves static pages with request logging and 404 handling. |
| 8 | [MERN Stack](Lab%208%20-%20MERN%20Stack/) | ShopperzCart converted into a full MERN app with a MongoDB-backed shopping cart and a Task Manager (Todo) with a REST API. |
| 9 | [Blog Management](Lab%209%20%20-%20Blog%20Management/) | BlogVault, a full-stack blog app to create, view, edit, and delete posts using React, an Express REST API, and MongoDB Atlas. |
